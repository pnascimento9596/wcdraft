## Positioning + voice

wcdraft is a fan-made, browser-native football draft game for people who know exactly why a 1970 fullback, a 1998 number ten, and a 2026 prospect all create different kinds of arguments.

Voice:

- Football-nerd: specific, tactical, and comfortable naming eras, formations, and tournament context.
- Stat-honest: no invented claims, no fake record lines, no unsupported "best ever" language, and no silent defaults.
- Era-romantic: make the all-time premise feel like a pub argument with receipts, not a sterile ratings table.
- Independent: never claims affiliation, endorsement, partnership, official status, or privileged tournament access.
- Owner bio already set: do not overwrite it from automation.

Pinned-content rule:

> wcdraft is a fan-made football draft game. Spin 17 World Cup squads, pick one player per spin, build an all-time XI, and run the full 2026 bracket in your browser. Not affiliated with any official competition or governing body.

## Content pillars

### 1. Daily Draft challenge

Use one seed/share-token of the day. The posted URL must be a real, reproducible `https://www.wcdraft.com/play/share?run=t1...` URL. Do not post a challenge if the token has not been generated and replay-checked.

Example posts:

1. Daily Draft 01: I hit the 8-0. Your turn. Same seed, same 17 spins, no excuses: {reproducible_share_url} Quote with your final XI and record.
2. Daily Draft: 4-3-3, one manager spin, full 2026 bracket. Beat my 8-0 or show me where the XI cracked: {reproducible_share_url}
3. Today's seed is rude to nostalgia. You get the same pool I got. Beat my 8-0: {reproducible_share_url}

Operational note: those examples are copy blocks, not publishable posts until `{reproducible_share_url}` is replaced by a token that was generated by the app and replayed from a clean browser URL.

### 2. Era spotlights

Hard licensing line: no player photos, portraits, likenesses, broadcast stills, trading-card art, or scraped imagery. Use text, wcdraft's own factual stat lines, and wcdraft pitch/UI renders only.

Example posts:

1. Era spotlight: 1970s defenders look different in wcdraft because the source record is different. Fewer modern event signals, more tournament-role context. That uncertainty is shown, not hidden. [attach our own pitch render]
2. The best all-time XI arguments usually start with attackers. The game gets more interesting when your second spin gives you a fullback and the formation has to survive it. [attach our own slot/pitch render]
3. 2026 cards are projected from factual career signals only. No proprietary ratings, no fan-vote scrape, no photo rights problem. If the source is thin, the UI should tell you. [attach our own candidate-row render]

### 3. Memory-mode reveal culture

Memory mode hides ratings during the draft and turns the reveal into the story. Use screenshots of our own UI only, especially before/after reveal states.

Example posts:

1. Memory mode test: if you picked him before seeing the number, you meant it. Screenshot your reveal. No photos, no hints, just your XI and the receipts.
2. The worst Memory-mode feeling: realizing your "obvious" pick was a vibes pick. The best one: being right anyway. Drop the reveal screen.
3. Today's Memory prompt: build the XI from names, years, flags, and what you remember. Reveal only after the run. Screenshots over hot takes.

### 4. Build-in-public + changelog

Use this pillar to explain real shipped changes and carryovers. Do not claim a fix is live until `origin/main`, CI, and deployment are verified.

Example posts:

1. Shipped: social cards now use the gold marketing banner, while the in-app SVG mark and PWA icons stay unchanged. Marketing art is for previews; gameplay UI keeps the canonical mark.
2. Changelog: attribution now stays visible on the draft pick screen, even where the footer is hidden for the anchored mobile action bar. Licensing guardrail, not decoration.
3. Backlog note: per-run dynamic OG cards are still separate server work. Static previews ship first; generated run-specific cards wait for the replay/OG lane.

## Cadence

Default schedule: 1 post/day on quiet days, 2 posts/day on major match days. Do not force filler. The bracket is the calendar.

Tournament hooks:

| Dates        | Calendar signal                                       | Post hook                                                                               |
| ------------ | ----------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Jun 11       | Opening day: Mexico v South Africa starts Group A     | Pinned intro + Daily Draft challenge tied to the first match window                     |
| Jun 12       | USA and Canada opening windows                        | Morning Daily Draft; evening Memory-mode prompt                                         |
| Jun 13-17    | First round of group openers rolls across Groups C-L  | Era spotlights keyed to the day's teams and positions, using only our own UI renders    |
| Jun 18-24    | Second group matches and early qualification pressure | "Who saved your bracket?" challenge posts; screenshot culture after close games         |
| Jun 25-27    | Final group matches; simultaneous-table anxiety       | Daily Draft + reveal-screenshot prompt; avoid live-score claims unless verified         |
| Jun 28-Jul 3 | Round of 32                                           | Knockout-path posts: "Can your XI survive the bracket?"                                 |
| Jul 4-7      | Round of 16                                           | One Daily Draft per match day; one changelog/build post if something actually shipped   |
| Jul 9-11     | Quarter-finals                                        | Era spotlights: compact, tactical, no player imagery                                    |
| Jul 14-15    | Semi-finals                                           | Memory-mode reveal posts; invite quote-post XI comparisons                              |
| Jul 18       | Bronze final                                          | Low-stakes challenge: weird XI, real token, reproducible URL                            |
| Jul 19       | Final                                                 | Pinned-content refresh only if counsel gate still blocks paid; organic challenge thread |

Practical cadence:

- 9:00-11:00 ET: Daily Draft challenge when there is a match slate.
- 30-60 minutes after a major match: one contextual post only if it uses verified match facts.
- Off days or travel days: changelog/build-in-public or Memory-mode prompt.
- Never exceed two posts/day unless Paulo manually runs a live thread.

## Automation design - future q-007

Design only; do not build in this lane.

Future poster shape:

- GitHub Actions cron runs a script daily.
- Source content lives in `docs/marketing/queue/*.md`.
- Each queue file has front matter: `status`, `scheduled_at`, `pillar`, `copy`, `media`, `share_url`, `dry_run`.
- Dry-run mode is default. It prints the selected post, media paths, and resolved URL, then exits without calling X.
- Publish mode requires `dry_run: false`, a real queue file, and a valid token URL for Daily Draft posts.
- The action posts through X API v2 using OAuth 1.0a user-context credentials.

Secrets Paulo would place in repository Actions secrets:

- `X_API_KEY`
- `X_API_SECRET`
- `X_ACCESS_TOKEN`
- `X_ACCESS_SECRET`

These go in GitHub repository Settings -> Secrets and variables -> Actions -> Repository secrets. They must not be committed, logged, echoed, or copied into docs beyond the names above.
